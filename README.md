# からだ つたえる（MieeL）

からだの ふちょうを ことばで いうのが むずかしい 子が、ゆびさしで「どこが」「どんなふうに」「どのくらい」「いつから」を つたえる アプリです（特別支援教育向け・iPad / iPhone）。

## できること
- 🩹 **どこが いたい？**：からだ マップ（まえ・うしろ、28かしょ：おでこ・ほっぺ・ひじ・てくび・あしくび・かかと など）を さわる → **みぎ・ひだり**（えを さわれば じどうで わかる）→ どんな かんじ（ずきずき・がんがん・きりきり・しびれる・くるしい など 16しゅるい）→ いたさ 0〜5（かおの え）→ いつから → おおきな「つたえる カード」と こえで つたえる
- 🏥 **からだの カード 32まい**：きもちわるい・はきそう・めが まわる・いきが くるしい・はなぢ・むしに さされた・ころんだ・せいりに なった など。しゃしんで カードを ふやせる
- 🎒 **びょういん れんしゅう 9しゅるい**：びょういん・はいしゃ・けんこうしんだん・じびか・がんか・さいけつ・レントゲン・くすりを のむ・ちゅうしゃ を、「すって・はいて」「あーん」「じっと」「5まで かぞえる」「ピーが きこえたら ✋」の うごきつきで
- 📋 つたえた ことは きろくに のこる（ほけんしつ・おうちとの れんらくに）
- **A4 プリント**：どこが いたい？ シート・からだの カード（きって つかう）・からだの きろく
- 🏠 ボタンで いつでも さいしょへ（つかって いる とちゅうは ながおし）

## こじんじょうほう
きろく・しゃしんは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
