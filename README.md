# からだ つたえる（MieeL）

からだの ふちょうを ことばで いうのが むずかしい 子が、ゆびさしで「どこが」「どんなふうに」「どのくらい」「いつから」を つたえる アプリです（特別支援教育向け・iPad / iPhone）。

## できること
- 🩹 **どこが いたい？**：からだ マップ（まえ・うしろ）を さわる → どんな かんじ（ずきずき・ちくちく など）→ いたさ 0〜5（かおの え）→ いつから → おおきな「つたえる カード」と こえで つたえる
- 🏥 **からだの カード**：きもちわるい・はきそう・さむい・やすみたい・ほけんしつに いきたい など。しゃしんで カードを ふやせる
- 🎒 **びょういん れんしゅう**：びょういん・はいしゃ・けんこうしんだん・ちゅうしゃ を、「すって・はいて」「あーん」「じっと」「5まで かぞえる」「ピーが きこえたら ✋」の うごきつきで
- 📋 つたえた ことは きろくに のこる（ほけんしつ・おうちとの れんらくに）
- **A4 プリント**：どこが いたい？ シート・からだの カード（きって つかう）・からだの きろく
- 🏠 ボタンで いつでも さいしょへ（つかって いる とちゅうは ながおし）

## こじんじょうほう
きろく・しゃしんは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
